# Фотоконтент: флакон и флакон с коробкой

Требование владельца: максимум две фотографии на аромат, в порядке:
1. Главная — флакон без коробки.
2. Флакон с коробкой.

Визуально просмотрены все 181 исходное изображение для 60 ароматов.
Выбор зафиксирован в resources/catalog/image-selection.json и встраивается
в единый PHP. Используется явная роль, а не автоматический выбор первых файлов.
Каталог показывает роль bottle; галерея — bottle, затем bottle_box.
Исходные JPEG не изменяются и не удаляются, дополнительные фото просто скрыты.

## Результат

- 57 ароматов: полная пара.
- 3 аромата: подходящий флакон есть, фото с коробкой нужно найти.
- 3 аромата: фотографий нет, нужно найти обе.
- Всего выбрано 117 изображений; все 181 исходный файл сохраняются.
