# Источники и замены отдельных фотографий

## Tom Ford Oud Wood — ID 11

По просьбе владельца заменён сероватый фон главной фотографии на белый.
Поиск в доступных публичных источниках не дал подходящего нового снимка.
Использована обработка исходного фото флакона 100 мл через инструмент
редактирования изображений; владелец просмотрел и одобрил результат.
Это не новая фотография, найденная в интернете.

Готовый JPEG хранится в resources/catalog/photos/11, имя включает хеш содержимого.
При публикации сначала загружается новый JPEG и сверяется SHA256, затем
обновляется единый PHP с выбором главного изображения. Старые файлы и фото
с коробкой не удаляются и не меняются. Новый файл используется в каталоге
и в первой позиции галереи, вторым остаётся прежний снимок с коробкой.
