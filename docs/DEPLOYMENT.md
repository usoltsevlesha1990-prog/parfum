# Публикация одного PHP-файла

Workflow `.github/workflows/deploy-review.yml` отправляет только
`review-site/index.php` по SFTP в
`/home/parfumplace/web/parfumplace.ru/public_html/catalog-review/index.php`.
Доступ: https://parfumplace.ru/catalog-review/index.php

Это автономный PHP 8.2+ файл без зависимостей и подключения к БД: он содержит
только снимок брендов, описаний ароматов и цен больших флаконов из бэкапа
01.11.2026. Список, поиск, фильтр бренда и пагинация формируются PHP через
параметры URL. Нет дизайна, корзины и оформления заказа.

Ключ деплоя хранится только в GitHub Actions secret `DEPLOY_SSH_KEY`.
Публичная часть установлена для пользователя `parfumplace` с ограничением
`restrict,command="internal-sftp"`. Отпечаток Ed25519-ключа сервера проверяется:
`SHA256:A3zj4MdiiGuCl2TK9enHX8q7QV7nQ/uL6W2pnNY+gZA`.
Если серверный ключ сменился, остановить загрузку и проверить новый отпечаток
через доверенный канал; не отключать проверку.

Пуш в main запускает процесс автоматически; возможен запуск вручную через
GitHub Actions → Publish catalog review. Перед загрузкой выполняются проверка
синтаксиса PHP и HTTP-тесты всех описаний. После — HTTPS-проверка сайта.
Результат загрузки и результат HTTP-проверки учитываются отдельно.
Существующие HTML-страницы на сервере не удаляются; открывайте index.php явно.
Главная страница сайта и исходная БД не меняются.

Пересборка из приватного локального извлечения каталога:
`python3 tools/build_single_php.py`. Тесты:
`PHP_BIN=/workspace/.parfum-runtime/bin/php python3 tests/Feature/single_php.py -v`.
В CI используется обычный `php` из образа GitHub runner.

## Переход на MySQL

Текущий `review-site/index.php` больше не содержит снимка. Он делает SELECT
по таблицам brands, products и product_prices при каждом запросе. SQL-запросы
параметризованы; сессия MySQL работает в режиме READ ONLY. Для сравнения цен
не используется float. Пробники и отливанты исключены.

Реквизиты читаются из окружения DB_* или закрытого файла
`/home/parfumplace/web/parfumplace.ru/private/database.php`, вне public_html.
Без реквизитов или при ошибке SQL возвращается 503, без статического fallback.
Деплой проверяет наличие закрытого конфига до замены текущей страницы.

Новая база Hestia создаётся однократно скриптом tools/setup_hestia_catalog.sh
из root-терминала сервера. Он создаёт parfumplace_catalog со случайным паролем,
импортирует только каталог из проверенного набора, не исполняет полный дамп
и отказывается работать поверх существующей базы/конфига. Пароль остаётся
на сервере и не передаётся в GitHub. Каталог tests/fixtures содержит только
товарные данные для первоначального импорта и CI; PHP-файл их не читает.
После успешной HTTP-проверки workflow удаляет только известные старые HTML-файлы
нашей выгрузки в catalog-review. Другие папки сайта и базы не затрагиваются.

## Публикация в корне домена

Текущая цель: `/home/parfumplace/web/parfumplace.ru/public_html/index.php`.
Каталог открывается по https://parfumplace.ru/. Закрытая конфигурация остаётся
в `private/database.php` домена. Прежний root index.html переносится в private
с уникальным именем запуска. После успешной проверки корня старая папка
catalog-review удаляется; неизвестные файлы внутри неё не удаляются автоматически
и остановят rmdir.
