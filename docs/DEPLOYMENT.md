# Автоматическая публикация просмотра каталога

Workflow `.github/workflows/deploy-review.yml` публикует только `review-site/*.html`
по SFTP от пользователя `parfumplace` в
`/home/parfumplace/web/parfumplace.ru/public_html/catalog-review/`.
Исходники PHP, дамп, JSON, реквизиты, заказы и персональные данные не загружаются.
Главная страница сайта и БД не изменяются. Файлы за пределами указанной папки
не удаляются. Повторная публикация заменяет одноимённые HTML-страницы.

Единственный необходимый секрет репозитория: `DEPLOY_SSH_KEY` — приватный
Ed25519-ключ без парольной фразы. Его публичная часть установлена для пользователя
`parfumplace` с `restrict,command="internal-sftp"`. Командная оболочка не требуется.
Ключ не хранится в исходниках; временный файл на исполнителе удаляется после работы.

Ключ сервера проверяется по независимо подтверждённому владельцем отпечатку:
`SHA256:A3zj4MdiiGuCl2TK9enHX8q7QV7nQ/uL6W2pnNY+gZA` (Ed25519).
Несовпадение останавливает загрузку. Проверка HTTPS также не отключается.

Запуск: GitHub → Actions → Publish catalog review → Run workflow.
Изменения HTML в ветке main запускают тот же процесс автоматически.
Если SFTP-загрузка прошла, а проверка сайта упала, смотрите конкретный шаг:
это разные результаты. Проверьте DNS, HTTPS и публичный путь сайта.

Текущий review-site — снимок каталога из предоставленного бэкапа. Чтобы обновить
его, выполните tools/export_review.php на новой локальной копии, проверьте
результат tools/check_review_export.py и обновите только HTML в review-site.
Не переносите сюда полный бэкап или чувствительные таблицы.
