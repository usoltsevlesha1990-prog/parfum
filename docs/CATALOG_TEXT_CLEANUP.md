# Очистка форматирования каталога

По поручению владельца текстовые поля brands и products приводятся к обычному
тексту. HTML-сущности декодируются, теги/комментарии удаляются, script/style
содержимое исключается, переносы и повторные пробелы заменяются одним пробелом.

Поля brands: name, short_note, description, meta_title, meta_description.
Поля products: name, gender, fragrance_group, top_notes, heart_notes, base_notes,
release_year, description, meta_title, meta_description.
SKU, slug, ID, связи, цены, объёмы, остатки и фотографии не изменяются.

Перед UPDATE исходные значения сохраняются JSON-файлом с правами 0600 в
private/backups домена, вне публичной папки. Изменения выполняются в транзакции;
после записи каждое выбранное поле повторно проверяется. При ошибке — rollback.
Повторный запуск не меняет уже очищенные значения.

Из-за SFTP-only доступа обслуживающий workflow использует кратковременный
POST-обработчик: случайный адрес, независимый 256-битный токен в заголовке,
на сервере хранится только хеш токена, срок действия 10 минут, одноразовая
блокировка повторного вызова. Обработчик удаляется в finally после операции.
Реквизиты MySQL и резервная копия остаются на сервере. В CI выводятся только
количества изменённых строк/полей; текст и пароли не журналируются.

Тесты: tests/Unit/plain_catalog_text.php и tests/Integration/clean_catalog_text.php.
Интеграционный тест работает только с временными таблицами локальной dev-БД.
