# Адреса ароматов

Основной адрес: `/<brands.slug>/<название-аромата>/`.
Примеры: `/dior/sauvage/`, `/tom-ford/tobacco-vanille/`.
Вторая часть получается из существующего SKU удалением начального slug бренда
(включая повторный префикс бренда). Если префикса нет, используется весь SKU.
База, SKU, ID и привязки фотографий не изменяются. Дубли адресов запрещены.

Каталог ссылается на основные адреса. Старые `index.php?sku=...` отвечают 301
на основной адрес, версия без завершающего слеша также перенаправляется.
В карточке указан canonical. Неверная пара бренд/аромат возвращает 404.
Ссылки навигации абсолютные от корня, фотографии остаются в `/pict/<ID>/`.

На текущем SFTP-only хостинге маршруты создаются как каталоги с символьной
ссылкой `index.php` на единственный корневой PHP-файл. Это даёт чистые URL
без изменения nginx/Apache и без копирования приложения. Скрипт публикации
читает актуальные публичные ссылки каталога, проверяет их уникальность,
не следует по посторонним символьным ссылкам и не заменяет чужие файлы.
При повторном деплое используется тот же корневой файл.

Проверки: tests/Feature/single_php.py, включая все 63 карточки и 301/404.

## Страницы брендов

Страница бренда: `/<brands.slug>/`, например `/yves-saint-laurent/`.
На ней выводятся только его ароматы. Все ссылки списка брендов и возврата
из карточки используют этот адрес. Старый `?brand=...` перенаправляется 301
с сохранением номера страницы и поискового запроса, если они присутствуют.
Пагинация бренда: `/бренд/?page=2`. Несуществующий бренд возвращает 404.
Файл маршрута бренда — ссылка `../index.php` на общий корневой PHP.
