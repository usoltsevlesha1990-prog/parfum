# PARFUM PLACE

Интернет-магазин парфюмерии мировых брендов для покупателей в России.
**Продаём только целые заводские флаконы. Пробники и отливанты не продаём.**
Планируемый домен: **parfumplace.ru**.

## Реализовано

- Простой HTML-каталог без дизайна, CSS и JavaScript с поиском по названию аромата и бренду,
  фильтром по бренду и пагинацией.
- Карточка аромата с описанием, пирамидой нот, объёмами и ценами.
- Чтение реальной структуры существующей БД через PDO и подготовленные запросы.
- Изолированная локальная копия только каталога: 9 брендов, 63 аромата,
  189 исходных вариантов объёма; в витрине доступны только 63 больших флакона
  (70, 75, 90, 100 мл). Варианты 5 и 10 мл исключены. Пользователь приложения имеет только SELECT.
- Безопасное извлечение каталога из бэкапа без выполнения SQL из файла.

Это этап витрины: корзина, заказы, оплата и администрирование ещё не реализованы.
По запросу владельца интерфейс не содержит дизайна и фотографий: только текст, ссылки и таблица цен.
Наличие показывать как подтверждённое пока нельзя: правила `stock` и городских
флагов необходимо уточнить. На странице прямо указано, что заказы недоступны.

## Стек и структура

PHP 8.2+, расширения `pdo_mysql`, `mbstring`; MySQL/MariaDB; HTML, CSS, JavaScript.
Внешних PHP/JS-зависимостей и этапа сборки пока нет. Автозагрузка реализована
в `bootstrap/app.php`, Composer не требуется.

```text
app/Infrastructure/      подключение PDO и репозиторий каталога
app/Application/         место для будущих сценариев
app/Domain/              место для будущих правил предметной области
app/Http/                место для будущих HTTP-контроллеров
bootstrap/               автозагрузка и проверенная схема локального каталога
config/                  конфигурация из окружения
public/                  единственный публичный корень
resources/views/         HTML-шаблоны с экранированием
routes/                  место для будущего маршрутизатора
storage/                 закрытые данные, исключены из Git
tools/                  извлечение каталога и локальный импорт
tests/                  модульные, интеграционные и HTTP-проверки
docs/                   анализ базы данных
```

## Запуск с подготовленной локальной базой

Передайте параметры через окружение процесса. `.env.example` документирует их;
автоматического чтения `.env` нет. Не помещайте секреты в Git.

```sh
cd /workspace/parfum
export DB_SOCKET=/workspace/.parfum-runtime/mysql.sock
export DB_NAME=parfum_place_dev
export DB_USER=parfum_reader
/workspace/.parfum-runtime/bin/php -S 127.0.0.1:8080 -t public public/router.php
```

В текущей облачной среде PHP и MariaDB подготовлены в `/workspace/.parfum-runtime`
вне репозитория. После перезапуска среды локальную MariaDB запускает
`sh tools/start_local_db.sh`. Это вспомогательный скрипт именно для подготовленной
облачной среды; на обычной машине используйте установленный `php` и свой локальный
сервер MySQL/MariaDB. Для TCP вместо `DB_SOCKET` задайте `DB_HOST`, `DB_PORT` и
пароль отдельного пользователя с SELECT только на таблицы каталога.

PHP development server предназначен для локальной разработки. При развёртывании
нужны PHP-FPM, веб-сервер с document root `public/`, HTTPS и отдельные безопасные
реквизиты. Никакие действия на боевом сервере сейчас не выполняются.

## Подготовка новой локальной копии из дампа

```sh
python3 tools/extract_catalog.py /path/to/backup.sql.gz
PARFUM_LOCAL_SOCKET=/absolute/path/to/isolated/mysql.sock php tools/import_local.php
```

Используйте только сокет отдельного локального dev-сервера. Импортёр создаёт
**новую** базу `parfum_place_dev` и отказывается работать поверх существующей.
Выполняется только проверенная схема из `bootstrap/catalog_schema.php`,
данные вставляются параметризованными запросами. SQL из дампа не выполняется.
Извлечение также отказывается перезаписывать существующий `catalog.json`;
для повторного анализа можно выбрать другой игнорируемый файл через `--output`.

Заказы, посетители, отзывы, настройки и прочие таблицы не импортируются.
Исходный бэкап и локальные данные не должны попадать в Git или `public/`.
Не запускайте полный SQL-дамп: он содержит DROP TABLE и чувствительные данные.

## Проверки

Из корня репозитория при запущенных локальных сервисах:

```sh
python3 -m unittest discover -s tests/Unit -p 'test_*.py' -v
DB_SOCKET=/workspace/.parfum-runtime/mysql.sock /workspace/.parfum-runtime/bin/php tests/Integration/catalog.php
python3 tests/Feature/http_smoke.py -v
```

HTTP-тесты по умолчанию обращаются к локальному порту 8080; изменить адрес можно
через `PARFUM_TEST_URL`. Интеграционные тесты рассчитаны на предоставленный каталог.
Они проверяют и запрет UPDATE для пользователя приложения (попытка не меняет строк).

Подробнее: [анализ БД](docs/DATABASE_ANALYSIS.md),
[архитектура](ARCHITECTURE.md), [план](DEVELOPMENT_PLAN.md).

## Ассортимент

Разрешённые объёмы текущей витрины заданы в `config/catalog.php`. Фильтр
применяется к списку, карточке и минимальной цене. Исходная копия данных
сохранена без удаления малых объёмов; они недоступны через витрину.
В схеме нет признака заводской упаковки: перед продажей нужно подтвердить
тип товара по данным поставщика. Новые объёмы добавляются в разрешённый список
после проверки; это предотвращает случайную публикацию пробников и отливантов.

## Просмотр базы без дизайна и выгрузка на сайт

Динамический вариант содержит текстовые ссылки, список брендов, пагинацию,
описания ароматов, ноты и таблицу цен. Корзина и оформление заказа отсутствуют.
CSS и JavaScript не подключаются.

Автономная версия генерируется из локальной базы, без реквизитов и SQL:

```sh
DB_SOCKET=/workspace/.parfum-runtime/mysql.sock /workspace/.parfum-runtime/bin/php tools/export_review.php
python3 tools/check_review_export.py
```

Результат: `storage/exports/parfumplace-catalog-review.zip`, 80 HTML-страниц,
включая 63 страницы ароматов. Архив содержит только папку `catalog-review/`.
Её можно загрузить в публичный каталог хостинга: просмотр будет доступен
по пути `/catalog-review/`. Все ссылки относительные; перенастройка PHP,
веб-сервера и подключения к боевой БД для этой версии не нужна.
Статическая версия не поддерживает поиск, но содержит все бренды и пагинацию.
Её цены — снимок предоставленного бэкапа, не обновляемые данные сайта.

Не заменяйте существующую папку без проверки её содержимого. Для повторного
экспорта укажите новый выходной каталог первым аргументом экспортёра.
Оба варианта отмечены `noindex, nofollow` до подготовки магазина к запуску.
Автоматическое размещение требует отдельно настроенного доступа к хостингу.

## Текущая версия для сервера

По последнему запросу владельца публикация переведена на один автономный PHP-файл
`review-site/index.php`. Он формирует страницы по параметрам URL из встроенного
снимка каталога; подключения к боевой БД нет. Рабочий путь —
`/catalog-review/index.php`. HTML-экспорт описан выше как предыдущий вариант.
